WEEKLY TEST

- BE동사부터 관계사/가정법/도치/분사구문 등 문법 개별 선택

SIMUL TEST
- 학교/학년/시험 설정
- 학교 기출 PDF 분석
- 이번 시험범위 지문 입력
- 학교 기출 문항 형식에 맞춘 새 문제 생성
- 수능/모의고사 전 유형 + 내신형 + 문법 유형 개별 선택
- 기존 출제 이력 DB와 비교해 재출제 억제

디자인
- WEEKLY TEST: GREY 표지 + 듣기/문법/독해/해석 점수칸 (총점/전체 문항수 표기 없음)
- SIMUL TEST: GREY 표지 + 점수칸 없음
- 내지: 심플 라인형 / 좌우 2단 / 중앙 세로 구분선
- 브라우저 인쇄 기능으로 PDF 저장 가능

v2.9 TYPE QUALITY GATE
- 빈칸 추론: MAIN CLAIM/핵심 결론/핵심 논리관계를 우선 빈칸으로 선정. 단순 세부사항·바로 앞 동의어 찾기형 금지.
- 무관문장: 소재가 전혀 다른 쉬운 문장 금지. 같은 주제/어휘를 공유하지만 전체 논리 흐름을 깨는 문장으로 출제.
- 문장 삽입: 지시어/대명사/관사/반복어/연결어/논리관계 중 최소 2개 이상의 배치 단서를 요구.
- 글의 순서: 단일 연결어만으로 결정되는 배열 금지. 최소 두 연결 관계를 추론하도록 설계.
- 요약문: 원문 문장 복사형 금지. 전체 핵심 관계를 상위 개념으로 재구성.
- 어법/어휘: 표면 단서만으로 답이 보이는 문항 금지. 실제 구문·문맥 판단을 요구.
- 2차 Choice QA에서 typeSpecificStrong를 판정하고 false인 핵심 유형은 서버가 최종 생성 결과를 거부.
